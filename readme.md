### Target (Supervised): diagnosis — (M = Malignant, B = Benign)

### Features:
`Id, diagnosis, radius_mean, texture_mean, perimeter_mean, area_mean, smoothness_mean, compactness_mean, concavity_mean, symmetry_mean, fractal_dimension_mean.`

### Brief description:
`The dataset contains 569 samples and 32 features including the target variable. Each sample represents a breast mass with features computed from a digitized image of a fine needle extract (FNA) of a breast mass. The features characterize various attributes of the visible cell nucleus in the digital image.`
